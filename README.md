# wfh
All-in-one tool for a more effective work-from-home strategy. 

This project provides a few valuable tools to a worker at home and their dependent family members. 

Worker:

  1. Easy clock in / clock out, with immediately visible time remaining, percentage time complete, expected quitting time, etc.

  2. Easy tomato timers

  3. Message delivery from configured dependents based on urgency.

  4. Eventually will sync with Google calendar to show your meeting status to dependents as well. 

Dependents:

  1. Ability to view worker's current status (time remaining, is in a tomato?, etc.)

  2. Ability to send messages to worker with parameterized urgency. Should this message be delivered after their current tomato is done? Or do I interrupt everything right now?

Project is a Spring Boot backend, backed by a dockerized Postgres database. Front end is React. 

Contributions are welcome.
